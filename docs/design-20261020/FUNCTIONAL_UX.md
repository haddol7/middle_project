# 기능·화면·상태 설계

설계일 2026-10-20. A01–A03을 하나의 사진 게시·재탐색 과정으로 제공한다. 추가 편집 도구, 추천 피드, 사진관·마을, 별도 서비스 이름은 범위에 포함하지 않는다.

## 사용자와 화면 구조

대상은 일상·후기 사진 한 장에 짧은 글을 붙여 공개 기록하는 사용자다. 방문자는 공개 사진을 보고 검색하며, 회원은 게시하고 자기 글의 분류·글자를 수정한다. 기존 API가 공개 조회를 제공하므로 개인 비공개 보관함처럼 안내하지 않는다.

기본 이동은 `사진`과 `내 글` 두 목적지다. 사진 화면에 검색 입력과 테마 필터를 두고, `사진 올리기`는 일관된 주요 행동으로 제공한다. 로그인·연결 설정은 상단 계정 메뉴에 둔다. 초기 화면에서 서버 주소나 기술 설명이 사진과 경쟁하지 않게 한다. 연결 실패 시에는 해당 설정으로 바로 가는 행동을 보여준다.

| 화면 ID | 화면 | 우선 보여줄 정보 | 주요 행동·복귀 |
| --- | --- | --- | --- |
| U01 | 사진 목록 | 사진, 제목, 작성자·날짜, 대표 테마, 태그 일부 | 사진 열기, 검색, 테마 선택, 올리기 |
| U02 | 사진글 작성 | 게시할 사진, 얼굴 확인 상태, 제목·본문, 분류·글자 요약 | 사진 선택, 얼굴 확인, 결과 수정, 게시 |
| U03 | 얼굴 확인 | 확대 가능한 사진과 가리기 적용 결과, 선택 영역 | 얼굴별 가리기/해제, 직접 영역 추가·이동·크기 조절, 강도·실행 취소·초기화, 적용 |
| U04 | 분류·글자 확인 | 추천 테마·대안, 태그, 사진과 글자 영역·문구 | 테마 변경, 태그 추가·삭제, 문구 교정·검색 제외, 완료 |
| U05 | 검색 결과 | 검색어, 테마·태그 조건, 사진과 일치 문구 | 결과 열기, 조건 해제, 다음 결과 |
| U06 | 사진글 상세 | 실제 공개 사진, 제목·본문, 확정 분류, 검색 출처 | 일치 영역 확대·이전/다음, 태그별 조회, 작성자만 수정·삭제 |
| U07 | 내 글 | 로그인한 사용자의 공개 게시글 | 새 글, 상세·수정; 비로그인 시 로그인 행동 |

U03·U04는 U02에서 여는 상세 편집 화면이다. 결과는 작성 화면의 같은 위치에 요약한다. 모든 기능을 강제 단계별 팝업으로 통과하게 만들지 않는다.

## 작성 화면의 정보 순서

상단은 뒤로 가기·`사진글 작성`, 하단에는 키보드와 겹치지 않는 `게시` 행동을 둔다. 본문 순서는 사진 미리보기 → 얼굴 확인 요약 → 제목·본문 → 분류 요약 → 사진 속 글자 요약 → 공개 안내다. 미리보기는 고정된 거대한 공간을 차지하지 않으며 원래 비율을 보존한다.

사진 선택 직후 얼굴 확인 화면에서 자동 처리 상태와 미리보기를 보여준다. 적용 후 작성 화면으로 돌아오면 확정 사본의 테마·글자를 분석한다. 제목·본문은 분석 중에도 쓸 수 있다. 분석이 끝난 정보만 갱신하며 입력 중인 글이나 사용자가 고친 분류를 덮어쓰지 않는다.

분류·글자 카드에는 상태와 다음 행동을 함께 보여준다. 예: `추천 테마: 음식 · 변경`, `사진 속 글자 3곳 · 확인`, `글자를 찾지 못했어요 · 다시 인식`. ‘정확도 95%’처럼 모델 점수를 실제 정답 확률로 표시하지 않는다.

## A01 얼굴 자동 모자이크

1. Android 사진 선택기로 이미지 한 장을 읽는다. 취소하면 기존 작성 내용으로 돌아간다. 원본 파일은 수정하지 않는다.
2. 화면 방향을 바로잡은 작업 사본에서 얼굴 위치를 찾고, 찾은 영역을 기본적으로 모두 모자이크한다. 얼굴 이름·신원을 판별하지 않는다.
3. 얼굴을 탭하면 선택 상태와 `가리기` 스위치가 보인다. 작은 얼굴은 영역 목록의 번호로도 선택한다. 본인 얼굴만 남기려면 사용자가 해당 얼굴의 가리기를 해제한다.
4. `직접 가리기`를 누르고 드래그해 사각형을 추가한다. 손잡이로 크기를 바꾸고 영역 안을 끌어 이동한다. 사진 이동·확대 모드와 영역 편집 모드는 선택 상태로 구분한다. 핀치 확대와 초기 배율 복귀를 제공한다.
5. 강도는 약/중/강 세 단계이며 중이 기본이다. 선택 영역에 적용하고, 영역을 선택하지 않았으면 활성 영역 전체에 적용한다. 영역별 값은 보존한다. 겹친 영역도 최종 사본에서 빠짐없이 가린다.
6. 실행 취소는 영역 추가·삭제·위치·강도·스위치 변경 한 번을 되돌린다. 초기화는 사용자가 이번 화면을 열었을 때 상태로 되돌린다. 재탐지는 별도 행동이며 수동 영역을 조용히 지우지 않는다.
7. `적용`을 누르면 실제 픽셀이 가려진 사본을 만든다. 단순 덮개 화면을 서버에 보내는 방식은 사용하지 않는다. 게시할 미리보기도 같은 사본이다.

탐지 실패는 ‘얼굴 없음’과 구분한다. 실패하면 `다시 찾기`와 `직접 가리기`를 제공한다. 얼굴 0개인 경우에도 직접 확인·보완할 수 있다. 자동 탐지만으로 모든 얼굴이 가려졌다는 보장은 표시하지 않는다.

모자이크 영역이 0개여도 사용자가 사진을 확인하고 적용했다면 게시할 수 있다. 얼굴 확인 화면을 건너뛴 상태에서는 게시 버튼 옆에 `사진의 얼굴을 먼저 확인해주세요`와 바로 가기 행동을 제공한다. 추가 확인 팝업을 매번 겹치지 않는다.

게시 후 서버에는 원본이 없으므로 가려진 부분을 복원할 수 없다. 모자이크를 해제해 다시 게시하려면 기기에서 원본을 다시 선택한다. 기존 게시 사본에서 추가로 가리기는 가능하다.

## A02 자동 테마·태그 분류

대표 테마는 하나, 태그는 여러 개다. 테마는 `음식 / 동물 / 자연·풍경 / 인물 / 건축·공간 / 사물 / 기타`이며 `미분류`는 별도 상태다. 기타는 사용자가 선택할 수 있고, 자동 추천이 불확실할 때는 미분류를 사용한다.

모델의 일반 이미지 라벨을 검토된 한국어 테마·태그로 연결한다. 확신할 근거가 약하면 미분류와 최대 3개 대안을 보여준다. 태그는 최초 최대 5개를 추천하고, 확정 태그는 10개까지 허용한다. 여행 여부, 추억, 기분처럼 사진만으로 단정할 수 없는 의미는 사용자가 입력한다.

사용자는 추천 테마를 다른 테마로 바꾸거나 미분류로 둘 수 있다. 추천 태그의 삭제와 직접 입력을 제공하며, 중복·공백 태그는 정리해 표시한다. 추천 수락과 직접 수정의 차이는 내부 기록에 남기되 사용 화면을 복잡하게 만들지 않는다.

분류하지 않고도 게시할 수 있다. 서버에 저장한 확정 테마·태그는 다시 로그인하거나 다른 Android 기기에서 받아도 유지된다. 사진 목록의 테마 필터와 태그 탭은 이 확정값을 기준으로 조회한다. 테마와 태그 조건을 함께 고르면 두 조건을 모두 만족하는 글을 보여준다.

게시 후 작성자만 분류를 수정할 수 있다. 재추천은 먼저 변경 제안을 보여주며 기존 확정값을 자동 교체하지 않는다. 수정 저장 중 다른 창에서 변경했다면 최신 값과 내 수정 내용을 구분하고 다시 적용할 수 있게 한다.

## A03 사진 속 글자 검색

모자이크까지 끝낸 공개 사본에서 한글·영문 글자를 인식한다. 검색 단위는 위치를 가진 줄이다. 사진의 번호 표시와 문구 목록을 연결해 사용자가 어느 부분의 인식 결과인지 확인한다.

문구를 고칠 수 있고 줄마다 `검색에 포함`을 끌 수 있다. 제외한 문구는 서버·검색 데이터에 보내지 않는다. 검색 제외는 사진 속 글자를 지우는 기능은 아니며 해당 설명을 편집 화면에 짧게 표시한다. 실제로 가려야 한다면 얼굴 확인 화면의 직접 영역 도구로 돌아갈 수 있다.

인식한 줄의 위치를 유지한 채 문구를 수정한다. 사진에 위치가 없는 새 문장을 임의로 추가하는 입력은 제공하지 않는다. 줄 전체를 제외하거나 포함할 수 있으며, 사진에서 잘린 문자 때문에 인식이 부정확해도 사용자가 수정할 수 있다.

검색 입력의 안내는 `사진 속 간판·메뉴·책 제목 검색`이다. 자동 OCR 검색은 글 제목·본문 검색과 구분한다. 초기 범위는 사진 속 글자 검색이며, 의미가 비슷한 문장을 알아듣는 자연어 검색을 약속하지 않는다. 한글·영문 대소문자·띄어쓰기 차이를 정규화하고 여러 검색어는 모두 포함한 글을 찾는다.

검색 결과에는 사진, 글 제목, `사진 속 글자: 바다라멘`처럼 일치 출처와 문구를 보여준다. 결과를 열면 해당 줄의 사각 영역을 강조하고 확대한다. 여러 줄이 일치하면 순서대로 이동할 수 있다. 정확히 한 글자 경계까지 알아낸 것처럼 표시하지 않고, 교정한 문구도 원래 줄의 영역을 강조한다.

테마 필터를 선택한 상태에서 검색하면 교집합을 보여준다. 검색어를 지우면 선택한 필터 목록으로 돌아가며, 상세에서 뒤로 가면 검색어·필터·스크롤 위치를 복원한다. 결과 없음에는 오타 확인·조건 해제를 제공한다. 네트워크 오류를 결과 0개로 표시하지 않는다.

| --- | --- | --- |
| S01 | 사진 선택 전/취소 | 입력한 글 보존, 사진 선택 행동 |
| S02 | 읽기·디코딩·얼굴 탐지 중 | 작업명 표시, 취소 가능, 게시 대기, UI 조작 멈춤 방지 |
| S03 | 얼굴 확인 필요/수동 편집 | 적용 전 변경을 미리보기, 영역별 선택·해제·보완 |

| S11 | 검색 중·빈 결과·실패 | 각 상태 구별, 이전 검색의 늦은 응답은 현재 결과를 덮어쓰지 않음 |
| S12 | 서버 수정 충돌 | 최신 서버 값 안내, 내 입력 보존, 불러오기 후 재적용; 자동 덮어쓰기 금지 |

분류·OCR 작업을 사용하지 않기로 선택하면 명시적인 미사용 상태로 게시한다. 일부 작업만 실패하면 성공한 기능의 결과를 유지한다. 전송 후 응답을 못 받은 경우 ‘게시 여부 확인 필요’를 표시하고 내 글을 조회해 확인하도록 한다. 자동으로 다시 POST하지 않는다.

뒤로 가기는 편집 변경을 취소할지 필요한 경우에만 묻는다. 화면 회전·일시적인 Activity 재생성에는 작업 사진 경로·편집 상태·입력 내용을 복원한다. 사용자에게 별도 임시보관함·백그라운드 재전송 기능을 추가하는 범위는 아니다. 복원 파일이 없으면 사진을 다시 선택하도록 알리고 글 입력은 가능한 범위에서 유지한다.

## UI 일관성과 검수 조건

사진 중심의 단순한 카드, 읽기 쉬운 한글 글꼴, 일정한 여백·버튼 위치·상태 표현을 사용한다. 48dp 터치 영역, 일반 본문 16sp 수준, 대비 4.5:1을 설계 목표로 삼는다. 선택 상태는 색상과 문구·체크를 함께 사용한다. 화면 읽기에는 버튼과 영역 번호를 설명하고, 정확한 드래그가 어려운 사용자를 위해 영역 이동·크기 조절 보조 버튼을 제공한다.

360dp·412dp 세로 화면, 키보드 표시, 글자 크기 확대, 밝은·어두운 환경, 화면 회전을 검수한다. 첫 사용자가 설명 없이 사진 선택→모자이크 확인→테마 교정→게시→문구 검색을 완료하는지 관찰한다. 클릭 수·소요 시간·실수·질문·복구 경로를 기록하고 수정 전후 화면을 남긴다. 자동 테스트와 사용성 관찰 결과는 별도로 보고한다.
