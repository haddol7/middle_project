# 모아 재설계 시안 검수 — 2026-10-19

이 기록은 서비스 재설계의 인터랙션 시안 검수다. Django·Android·PythonAnywhere 구현 완료나 평가 통과 증빙이 아니다. 실행 중인 기존 앱은 아직 사진관 버전이다.

## 검수 범위

Windows Codex 브라우저에서 시안을 열었다. WSL Ubuntu의 프로젝트 venv로 visualize 미리보기 wrapper를 생성하고 임시 정적 서버로 제공했다. 외부 API 호출과 실제 서버 게시를 사용하지 않았다. 사진 장면은 CSS로 만든 샘플 일러스트다.

| 항목 | 관찰 결과 |
| --- | --- |
| 제목·본문 검색 | `바다` 입력 후 일치하는 기록 1개와 검색 결과 수 표시 |
| 저장·저장 목록 | 바다 기록 저장 후 저장 목록 2개, 버튼 선택 상태 확인 |
| 작성 중단·복귀 | 제목·본문 입력 → 나중에 계속 → 초안 열기 후 내용 유지 |
| 사진 누락 | 사진 없이 게시 선택 시 사진 선택 안내 표시 |
| 예시 기록 작성 | 예시 사진 선택 후 입력 내용으로 상세 이동, 시안 내 추가 안내 표시 |
| 사진 확대 | 상세 사진 선택 후 확대 상태와 축소 행동 표시 |
| 작은 화면 | 320px viewport에서 2열 목록·제목 줄바꿈·하단 탐색이 겹치지 않음 |
| 새로고침 | 샘플 목록 복귀, 저장 상태 복원 확인; 시안에서 추가한 기록은 영구 저장하지 않음 |
| JavaScript | Node `vm.Script`로 script 1개 컴파일 성공; 브라우저 수집 오류 로그 0개 |

미리보기의 iframe에서 네이티브 form submit이 실행되지 않아 로컬 버튼 핸들러로 수정했다. 실제 파일 선택 창은 자동화에서 열리지 않아 파일 선택·FileReader·형식/용량 오류는 검증 완료로 집계하지 않는다. 대신 `예시 사진 사용`으로 작성 흐름을 검수했다.

## 검증하지 않은 사항

- 실제 인증·서버 연결·사진 업로드·파일 접근 권한·계정별 보관·네트워크 복구
- Android APK와 기기에서의 검색·저장·재시작 후 사진 초안 복원
- PythonAnywhere 배포와 Android 동기화
- 구현을 모르는 사용자의 과업 수행 관찰

사진 초안은 시안에서 영구 보관하지 않는다. 실제 A5 구현에서는 앱 내부 사진 복사 또는 지속 가능한 URI 권한과 재시작 검증이 필요하다. 기존 환경 복원 테스트 통과 수를 이 시안의 새 기능 검증으로 재사용하지 않는다.
