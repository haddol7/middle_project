## 각 등록 항목과 남은 주의점

### 내용으로 정리하고 글자로 다시 찾기

- C01 사진 내용 기반 테마·태그 추천과 교정 — Android: Android가 사진 회전·축소·분석 수명주기, 분류 제안 칩, 선택 이유와 미확정 상태, 결과 교정 화면을 담당한다.
- C02 사진 속 글자로 다시 찾기와 일치 영역 표시 — Android: Android가 인식 수행, 공개 전 텍스트 포함 여부 확인, 검색어 강조, 회전·확대에 맞는 영역 표시를 제공한다.
- S01 사진 내용 기반 테마·태그 추천과 교정 — 서버: PA Django가 원시 제안과 사용자가 확정한 태그를 구분 저장하고 작성자별 수정 권한·분류별 목록 API를 제공한다. 기존 공개 Post 배열을 유지한다. 개별 사진의 이미지 지문·분석 버전·수정 revision을 검사하는 분석 결과 적용 API를 포함한다. 기존 사진에도 같은 API를 적용할 수 있으나 대량 진행·재개 UI는 F25다.
- S02 사진 속 글자로 다시 찾기와 일치 영역 표시 — 서버: PA Django·SQLite에서 게시글별 OCR 텍스트와 원본 기준 좌표·해시·분석 버전을 저장하고 제한된 데이터에 대해 검색·강조 위치를 응답한다. 긴 요청·외부 모델 서버는 쓰지 않는다.

독립 추가 기능 인정 위험: high. 공유 SDK를 별도 슬롯으로 세지 않았고 실제 필요한 데이터 공급 기능을 포함했다. 기본 과제 ID1–13과 실제 PA↔Android 동작은 전제다.
